# 23. Очистка UI/UX, платформенные доработки Android и оптимизация анимаций

**Status:** [x] DONE

**Приоритет:** P1 (Высокий)  
**Платформы:** Android, Desktop (UI/UX)

## Контекст
- По результатам тестирования на устройстве и десктопе накопился ряд UX-проблем и лишних элементов интерфейса:
  - Режим для левшей в настройках/интерфейсе не нужен и усложняет UI.
  - Во вкладке «Передачи» при разворачивании списка скачанных файлов появляется скроллбар, который сдвигает вёрстку интерфейса.
  - Модуль веб-ссылок (`videolink`) не должен отображаться/использоваться на Android.
  - В настройках на Android неудобно задавать папку загрузок — справа от поля ввода нужна кнопка выбора папки через системный пикер.
  - Общая производительность UI и анимаций проседает (ощущается как ~15 FPS), при быстром переключении вкладок анимации дёргаются, а также отсутствуют свайп-жесты для переключения между вкладками.

## Задачи
- [x] 1. **[P1] Удаление режима для левшей и скрытие веб-ссылок на Android**:
   - Удалить настройку и логику «режима для левшей» из UI, состояния и переводов (`src/`).
   - Скрыть/отключить вкладку и функциональность веб-ссылок (`videolink`) на платформе Android (оставить только на Desktop).
- [x] 2. **[P1] Фикс скроллбара во вкладке «Передачи» и кнопка выбора папки загрузок на Android**:
   - Устранить сдвиг интерфейса при появлении скроллбара в развёрнутом списке скачанных файлов во вкладке «Передачи» (скрыть визуальный скроллбар или зафиксировать layout без смещения контента).
   - В настройках на Android добавить справа от поля пути загрузок кнопку выбора папки (через SAF / системный выбор директории) с сохранением выбранного пути/URI.
- [x] 3. **[P1] Оптимизация производительности UI, плавности анимаций и свайп-жесты между вкладками**:
   - Провести аудит ре-рендеров и тяжёлых CSS-эффектов (например, `backdrop-filter`, тени, layout-триггеры), перевести анимации на GPU-композитные свойства (`transform`, `opacity`) и устранить дёрганье при быстром переключении вкладок.
   - Добавить свайп-жесты (влево/вправо) для плавного переключения между вкладками без конфликтов со скроллом списков.
