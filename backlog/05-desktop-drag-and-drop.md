# 05. Drag & Drop файлов на карточку устройства (Desktop)

**Status:** Done  
**Приоритет:** Средний  
**Платформы:** Windows, Linux

## Что нужно сделать
1. Подключить `getCurrentWebview().onDragDropEvent(...)` из `@tauri-apps/api/webview` в `DevicesView.tsx`.
2. При наведении файлов на окно подсвечивать карточки онлайн-устройств (использовать уже заготовленный ключ `t.devices.dropHint`).
3. Определять карточку под курсором (`document.elementFromPoint(x, y)` с `data-peer-id`) и при отпускании сразу запускать `api.sendFiles(peerId, paths)`.
4. Если файлы брошены мимо конкретной карточки, но в сети одно устройство — предлагать отправить ему, либо показывать быстрый выбор устройства.
