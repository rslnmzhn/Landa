# 24. Обновление иконки в десктопных приложениях (Windows / Linux)

**Status:** [!] BLOCKED

**Приоритет:** P1 (Высокий)  
**Платформы:** Windows, Linux (Desktop)

## Контекст
- После обновления иконки в EPIC-020 в десктопных сборках (Windows / Linux) по-прежнему отображается старая иконка приложения (в окне, панели задач, трее, `.exe` / `.AppImage` / `.deb` и т.д.).
- Необходимо проверить, какие именно файлы иконок (`src-tauri/icons/icon.ico`, `icon.png`, `32x32.png`, `128x128.png`, `128x128@2x.png`, `index.html`, ресурсы сборки Windows/Linux) содержат старую графику или не подхватываются при сборке, и заменить их на актуальную новую иконку.

## Задачи
- [x] 1. **[P1] Проверить и перегенерировать десктопные иконки из актуального исходника**:
   - Проверить содержимое `src-tauri/icons/` (`icon.svg`, `icon.ico`, `icon.png`, `32x32.png`, `128x128.png`, `128x128@2x.png`), `index.html` и `src-tauri/build.rs` / `tauri.conf.json` на наличие старой иконки.
   - Перегенерировать все десктопные форматы (`.ico` со всеми размерами 16–256px, `.png` для Tauri bundle и Linux `.desktop`/AppImage) из актуальной новой иконки.
- [!] 2. **[P1] Проверить отображение новой иконки в десктопных сборках**:
   - Убедиться, что в собранных артефактах Windows (`.exe` / установщик, заголовок окна, панель задач) и Linux (AppImage / `.deb`, иконка окна) отображается новая иконка.
   - **Windows (проверено):** `landa-app.exe`, `Landa_0.5.0_x64-setup.exe` (после добавления `bundle.windows.nsis.installerIcon` в `src-tauri/tauri.conf.json`), заголовок окна и панель задач Windows отображают новую иконку (подтверждено скриншотами через `agent-desktop`).
   - **Linux (блокер):** локально на Windows-хосте нет установленного дистрибутива WSL и не запущен Docker daemon — сборка и визуальная проверка AppImage / `.deb` требуют запуска на Linux-хосте или в GitHub Actions CI (`ubuntu-latest`).
