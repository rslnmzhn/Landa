# 10. Диагностика, выбор сетевых интерфейсов и релизная подпись

**Приоритет:** Средний  
**Платформы:** Windows, Linux, Android

## Что нужно сделать
1. **Выбор сетевых диапазонов / адаптеров в настройках**:
   - Показывать список обнаруженных LAN-интерфейсов (`enumerate_lan_interfaces`) в `SettingsView` с возможностью вручную включать/исключать конкретные подсети (аналог `DiscoveryNetworkScopeStore` из оригинальной Landa).
2. **Диагностика и просмотр логов**:
   - Писать ротируемый лог-файл (`landa.log`, последние N строк) в `app_data_dir`.
   - Добавить в `SettingsView` кнопку «Открыть логи» / «Скопировать диагностику» для быстрого разбора сетевых проблем.
3. **Постоянная релизная подпись Android в GitHub Secrets**:
   - Сгенерировать постоянный `.jks` keystore и добавить в GitHub Repository Secrets:
     - `ANDROID_KEYSTORE_BASE64`
     - `ANDROID_KEYSTORE_PASSWORD`
     - `ANDROID_KEY_ALIAS`
     - `ANDROID_KEY_PASSWORD`
   - Это нужно, чтобы новые версии APK ставились поверх старых как обновление без удаления приложения (сейчас при отсутствии секретов используется fallback debug-подпись).
4. **Идентификатор приложения (`tauri.conf.json`)**:
   - Tauri предупреждает, что `dev.landa.app` заканчивается на `.app` (конфликт с расширением бандлов на macOS). Если планируется сборка под macOS, стоит сменить `identifier` на `dev.landa.transfer` или `io.github.rslnmzhn.landa` (учитывая, что смена `applicationId` на Android создаст новое приложение при установке).
