**Status:** [x] DONE

**Приоритет:** Низкий

## Контекст
В оригинальной Landa была функция расшаривания одного видеофайла по локальной HTTP-ссылке с паролем (`http://<ip>:40444/watch`), чтобы открыть его в браузере на ТВ или другом устройстве без установки приложения.

- [x] 1. Создать опциональный крейт `crates/landa-mod-videolink` (подключаемый через Cargo feature `mod-videolink` и переключатель в настройках).
- [x] 2. Поднять лёгкий локальный HTTP-сервер (`tokio` + `hyper` или `axum`) с:

   - Потоковой отдачей видео с поддержкой заголовка `Range` (`206 Partial Content`) для перемотки.
   - Минимальной HTML5-страницей плеера.
- [x] 3. В UI добавить выбор файла, задание пароля, кнопку запуска/остановки и копирования ссылки.
