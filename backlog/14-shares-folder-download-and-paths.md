# 14. Скачивание папок целиком в Shares и отображение путей к файлам

**Status:** [x] DONE

**Приоритет:** P1 (Высокий)  
**Платформы:** Android, Windows, Linux

## Контекст
- В `SharesView.tsx` и `crates/landa-mod-shares/src/lib.rs` сейчас можно скачать только отдельный файл (`ShareRequest::DownloadFile`), а у папок и корней общих папок нет кнопки скачивания целиком.
- В интерфейсе не видно полный путь к файлу:
  - В `SharesView.tsx:382-387` хлебные крошки обрезаются в узком бейдже (`max-w-[180px] truncate`), а у локальных шар отображается только имя без пути.
  - В `ActivityView.tsx:287` для многофайловых передач выводится только `extractFileName(savedPath)` (без подпапок и пути сохранения), а для одиночных передач имя/путь файла вообще не отображаются в карточке.

## Задачи
- [x] 1. **[P1] Скачивание целой папки (и корня шары) в модуле `Shares`**:
   - Расширить протокол `SharesModule` (`crates/landa-mod-shares/src/lib.rs`): добавить рекурсивный обход каталога (как для локальных ФС-путей, так и для Android SAF `content://` через `ShareContentProvider`) с лимитами глубины/количества файлов и строгой санитаризацией относительных путей (`validate_relative_path`).
   - Реализовать скачивание папки целиком с сохранением структуры подпапок в `download_dir` (на Android — публикация в `MediaStore.Downloads` с сохранением `Download/Landa/<folder>/<relPath>`), проверкой целостности BLAKE3, отображением прогресса и записью в историю передач.
   - Добавить кнопку скачивания на карточки/строки папок и корней в `src/features/shares/SharesView.tsx` (в режимах «Список» и «Плитка»).
   - Добавить интеграционный тест в `crates/landa-mod-shares/tests/shares_test.rs` на скачивание вложенной папки и отклонение path traversal.
- [x] 2. **[P1] Отображение пути к файлу в `SharesView` и `ActivityView`**:
   - В `src/features/shares/SharesView.tsx`: сделать путь текущей директории (хлебные крошки) полностью читаемым и кликабельным для перехода на любой уровень вверх, а также показывать путь/URI у локальных шар.
   - В `src/features/activity/ActivityView.tsx`: показывать имя и путь принятых/отправленных файлов (включая относительный путь подпапок при передаче папок и итоговый путь сохранения в `Downloads/Landa/...`).
