# 03. Лёгкий встроенный предпросмотр файлов (фото, видео, аудио, текст)

**Status:** [x] DONE
**Приоритет:** Средний  
**Платформы:** Windows, Linux, Android

## Контекст
В оригинальной Landa был тяжёлый просмотрщик на `media_kit` (`libmpv`), который весил десятки мегабайт и сильно нагружал сборку и память. В Landa 2 стоит сделать **ультралёгкий** встроенный просмотрщик прямо на базе системного WebView (без `libmpv` и нативных кодеков).

## Что нужно сделать
1. **Tauri Asset Protocol / локальный стриминг**:
   - Включить `assetProtocol` в `src-tauri/tauri.conf.json` (с ограниченным scope на папку загрузок и `Shares`) или отдавать локальные файлы через безопасный кастомный URI-протокол с поддержкой `Range`-запросов для перемотки видео.
2. **Стеклянная модалка / экран предпросмотра (`src/features/preview/`)**:
   - **Изображения** (`.png`, `.jpg`, `.jpeg`, `.webp`, `.gif`, `.svg`): просмотр с зумом/панорамированием.
   - **Видео** (`.mp4`, `.webm`, `.mov`): нативный HTML5 `<video controls>` (использует аппаратные декодеры WebView2 / WebKitGTK / Android WebView).
   - **Аудио** (`.mp3`, `.wav`, `.ogg`, `.flac`, `.m4a`): компактный стеклянный плеер `<audio>`.
   - **Текст / код / логи** (`.txt`, `.md`, `.json`, `.log`, `.rs`, `.ts` и т.д.): чтение первых 512 КБ–2 МБ в моноширинном блоке.
   - Кнопка «Открыть в системном приложении» (`tauri-plugin-opener`) как fallback для неподдерживаемых форматов (`.pdf`, `.mkv`, архивы и т.д.).
3. **Точки входа**:
   - Клик по принятому файлу в `ActivityView` (история передач).
   - Предпросмотр файла перед скачиванием или после скачивания в `SharesView`.
